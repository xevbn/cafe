# Domain Model

## Menu

메뉴를 표현하는 Entity이다.

- 메뉴 이름
- 가격
- 메뉴 상태

## Inventory

메뉴의 재고 상태와 재고 변경 규칙을 담당한다.

- 메뉴 식별자
- 재고 수량

### 책임

- 재고 감소
- 재고 부족 검증

## Order

주문을 표현하는 Entity이다.

- 사용자 식별자
- 주문 번호
- 주문 당시 금액 합
- 주문 상태

### 책임

- 주문 생성
- 주문 상품 생성

## OrderItem

주문 메뉴를 표현하는 Entity이다.

- 메뉴 식별자
- 주문 수량
- 주문 당시 가격

## Point

사용자의 포인트를 표현하는 Entity이다.

- 사용자 식별자
- 잔액

### 책임

- 포인트 금액 검증
- 포인트 사용
- 포인트 추가

## OutboxEvent

외부 데이터 수집 플랫폼에 이벤트 정보를 손실없이 전송하기 위한 데이터를 저장하는 Entity
