# Domain Glossary

프로젝트에서 사용하는 주요 도메인 용어를 정의한다.

## 용어

| 용어    | 정의                      | 비고 |
|-------|-------------------------|----|
| 사용자   | 서비스를 이용하는 주체            |    |
| 메뉴    | 사용자가 주문할 수 있는 판매 대상     |    |
| 주문    | 사용자가 상품을 구매하기 위해 생성한 정보 |    |
| 주문 상품 | 주문에 포함된 개별 상품 정보        |    |
| 포인트   | 사용자가 주문을 위해 사용하는 통화     |    |


## 상태

### OrderStatus

| 상태     | 설명         |
|--------|------------|
| PAID   | 결제가 완료된 상태 |
| FAILED | 결제에 실패한 상태 |

### OutboxEvent

| 상태        | 설명               |
|-----------|------------------|
| PENDING   | 이벤트가 처리 대기 중인 상태 |
| PROCESSED | 이벤트가 처리된 상태      |
| FAILED    | 이벤트 처리에 실패한 상태   |
