# UC-03 커피 주문

## 목적
사용자가 커피를 주문한 경우 포인트로 커피를 주문한다.

## Actor
사용자

## 입력
- 사용자 식별값
- 메뉴 ID
- 수량

## 사전 조건
- 메뉴가 존재해야 한다.
- 주문 가능한 재고가 있어야 한다.

## 정상 흐름
1. 사용자 식별값으로 Point를 조회한다.
2. 메뉴 ID로 Menu를 조회한다.
3. 메뉴의 가격을 확인한다.
4. 메뉴의 재고를 확인한다.
5. 사용자의 포인트 잔액을 확인한다.
6. 재고를 차감한다.
7. 포인트를 차감한다.
8. Order를 생성한다.
9. 주문 정보를 저장한다.
10. 주문 이벤트를 OutboxEvent로 저장한다.
11. 주문 결과를 반환한다.

## 예외 흐름

### 메뉴가 존재하지 않는 경우
- 주문을 중단한다.

### 재고가 부족한 경우
- 주문을 중단한다.
- 포인트를 차감하지 않는다.

### 포인트가 부족한 경우
- 주문을 중단한다.
- 포인트를 차감하지 않는다.
- 재고를 차감하지 않는다.

### 주문 저장에 실해나 경우
- 주문 처리를 롤백한다.

## 결과
- 주문이 생성된다.
- 포인트가 주문 금액만큼 차감된다.
- 재고가 주문 수량만큼 차감된다.
- 외부 데이터 전송을 위한 OutboxEvent가 생성된다.
