# UC-02 포인트 충전

## 목적
사용자의 포인트를 충전한다.

## 입력
- 사용자 식별값
- 충전 금액

## 정상 흐름
1. 사용자가 식별값으로 Point를 조회한다.
2. 충전 금액의 유효성을 검증한다.
3. Point의 충전 기능을 호출한다.
4. 변경된 Point를 저장한다.

## 예외 흐름

### 충전 금액이 유효하지 않은 경우
- 포인트 충전을 중단한다.
- 잘못된 충전 금액 오류를 반환한다.

### 동시에 충전 요청이 발생한 경우
- Point의 동시성 제어를 통해 잔액의 정합성을 보장한다.

## 결과
사용자의 포인트 잔액이 충전 금액만큼 증가해야 한다.
